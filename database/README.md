# SQLite 复现材料

本目录公开外卖平台的表结构、合成初始化数据和代表性缺陷回归快照。原始 `.db` 文件没有上传，因为其中可能包含本机测试残留、账号和历史记录，而且二进制文件不便于代码审查。

## 使用方法

```bash
sqlite3 takeaway_test.db < schema.sql
sqlite3 takeaway_test.db < seed_test.sql
```

初始化后包含 4 个合成角色账号、2 条菜品和 1 条订单。手机号、地址、标识和密码均为公开演示值。

`snapshots/` 中的 JSON 是根据实际专项测试证据脱敏整理的前后状态，保留了 SQL 单引号和金额精度问题的判断依据，不含真实用户数据。
