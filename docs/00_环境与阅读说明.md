# 测试环境与使用说明

测试在独立副本与时间命名的临时目录执行，未修改原项目和原数据库。

运行模式：Qt offscreen，UDP地址127.0.0.1，动态选择空闲端口；具体端口见证据/本轮网络配置.xml。无浏览器访问地址，服务已停止。

数据库：每轮创建独立 `CustomMenuSys.db`。初始化 0 用户、0 菜品、0 订单；使用合成账号 910001 至 910004，对应商户、顾客、骑手和管理员。角色来自程序枚举 10 至 13。

复现：构建 `src/TakeawayPlatformService.pro` 后，设置 `TAKEAWAY_SERVER_EXE` 与可选的 `QT_RUNTIME_BIN`，运行 `python tests/udp_regression.py`。脚本创建新的时间命名目录、测试库及动态端口，不重用历史数据库。

阅读顺序：06_外卖测试报告.pdf查看总结与缺陷；07_用例执行与缺陷.xlsx筛选用例；Markdown文件可编辑；证据目录保留历轮JSON、最终库、脚本和网络配置。

原数据库在测试前后通过 SHA-256 校验保持不变；公开仓库不包含原数据库、测试运行数据库或本机绝对路径。
