# 测试计划与范围

日期：2026-09-16。本文件依据本轮执行整理，不表示已获得需求方评审。

目标：验证外卖服务端的注册、菜品与订单协议处理、数据有效性、重复操作、认证边界与重启持久性，形成可复核的测试材料。

对象：现有Qt服务端编译产物；C++、Qt、UDP、SQLite。真实调用服务端，不通过数据库直接写入来冒充业务操作。

方法：等价类、边界值、状态转换、场景法；将请求数据与数据库前后快照、UDP响应对照。功能层次限定为协议层，不能替代客户端UI全流程验证。

进入条件：独立可执行程序、独立数据库和回环端口准备完成，收到服务端心跳，三张业务表可读。

退出条件：计划内48项获得执行结果，失败关联缺陷及数据证据，记录未测试范围；不以全通过为强制结束条件。

优先级：P1优先关注订单丢失、重复、金额错误与认证缺失；P2关注字段校验。优先级为测试建议，待需求评审。

本轮未修改业务代码，缺陷未修复，不存在修复后回归通过结论。服务进程均在本轮结束后关闭。

未测试：客户端登录与按钮、真实购物车和优惠计算、两个骑手争抢同一订单、客户端多角色权限、丢包/乱序/重传、性能压力、兼容性、真实支付和地图接口。

这些未测试范围不纳入48项分母。没有UI截图，也没有把协议请求结果包装为界面测试截图。
